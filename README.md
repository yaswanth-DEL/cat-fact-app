# Cat Facts App

A simple one-page app that fetches random cat facts using a public API.

## Features
- Fetches live cat facts
- Uses Fetch API
- Simple responsive UI

## API Used
https://catfact.ninja/

## How to Run

1. Clone the repository

```bash
git clone <your-repo-url>
```

2. Open the folder

```bash
cd cat-fact-app
```

3. Open `index.html` in browser
